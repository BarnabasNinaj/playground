# playground

Progressive Web App for Montessori activities, STEM workshops, bilingual songs (SK/CZ), and stage-by-stage parenting tips (6–36 months).

## Stack

- React + Vite
- Tailwind CSS v4
- Lucide React
- PWA manifest + service worker
- Vercel-ready (`vercel.json`)

## Develop

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run preview
```

Push to GitHub and import the repo in [Vercel](https://vercel.com) — framework preset: Vite.
